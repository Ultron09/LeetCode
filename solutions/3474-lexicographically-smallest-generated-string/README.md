## 📌 Problem Statement

You are given two strings, `str1` and `str2`, of lengths $n$ and $m$, respectively.

A string `word` of length $n + m - 1$ is defined to be generated by `str1` and `str2` if it satisfies the following conditions for each index $0 \le i \le n - 1$:
- If `str1[i] == 'T'`: `word[i .. i + m - 1] == str2`.
- If `str1[i] == 'F'`: `word[i .. i + m - 1] != str2`.

Return the **lexicographically smallest** possible string that can be generated by `str1` and `str2`. If no string can be generated, return an empty string `""`.

### Example 1:
```
Input: str1 = "TFTF", str2 = "ab"
Output: "ababa"
Explanation:
- Index 0 ('T'): "ab" == "ab"
- Index 1 ('F'): "ba" != "ab"
- Index 2 ('T'): "ab" == "ab"
- Index 3 ('F'): "ba" != "ab"
Both "ababa" and "ababb" satisfy conditions; "ababa" is lexicographically smaller.
```

### Example 2:
```
Input: str1 = "TFTF", str2 = "abc"
Output: ""
Explanation: Overlapping 'T' constraints at 0 and 2 require contradictory characters.
```

### Example 3:
```
Input: str1 = "F", str2 = "d"
Output: "a"
```

### Constraints:
- $1 \le n == \text{str1.length} \le 10^4$
- $1 \le m == \text{str2.length} \le 500$
- `str1` consists only of `'T'` or `'F'`.
- `str2` consists only of lowercase English letters.

---

## 💡 Intuition & Approach

### 1. Mandatory Placement from 'T' Constraints
- Any position $i$ with `str1[i] == 'T'` strictly fixes `word[i + j] = str2[j]` for all $0 \le j < m$.
- If two `'T'` placements demand different characters at the same index, a contradiction exists $\implies$ immediately return `""`.

### 2. Lexicographically Minimal Default
- To make `word` lexicographically smallest, fill all remaining unfixed positions with `'a'`.

### 3. Resolving 'F' Constraints (Rightmost Breaking)
- Iterate from $i = 0$ to $n - 1$:
  - If `str1[i] == 'F'` and `word[i .. i + m - 1] == str2`:
    - We must break this equality by changing at least one character.
    - To minimize lexicographical impact, we change a character as far right as possible (largest index $j \in [i, i + m - 1]$) that is **not fixed** by a `'T'` constraint.
    - Since `word[j]` was `'a'` (and equal to `str2[j - i]`), changing `word[j]` to `'b'` breaks the match and maintains the lexicographical minimum.
    - If no unfixed position exists in the window $[i, i + m - 1]$, return `""`.

### 4. Final Validation Pass
- Re-verify all $n$ constraints to confirm no later modifications inadvertently invalidated prior windows.

---

## ⚡ Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N \cdot M)$ where $N \le 10^4$ and $M \le 500$
  - Enforcing `'T'`: $\mathcal{O}(N \cdot M)$.
  - Resolving `'F'`: $\mathcal{O}(N \cdot M)$.
  - Verification: $\mathcal{O}(N \cdot M)$.
  - Total operations $\le 1.5 \times 10^7$ ($< 10$ ms in C++).
- **Space Complexity:** $\mathcal{O}(N + M)$ auxiliary space for the output string and fixed-position indicator array.

---

## 🔍 Edge Cases Considered

- **$M = 1$**: Single character windows; direct matching.
- **All `'T'` / All `'F'`**: Handled naturally without branch deviations.
- **Unfixed character modifications**: Changing to `'b'` is strictly sufficient because `'a'` was the colliding character.
